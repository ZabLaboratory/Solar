## Change

`NativeSceneAssets` now bounds remote URL entries and content-addressed dynamic image bytes independently. Dynamic entries are evicted only when their frame/patch leases are released; source archive bytes stay immutable. Image bodies are streamed with actual-byte accounting, capped at 8 MiB per image, 128 retained entries / 64 MiB total, and eight concurrent downloads. The queue admits small downloads by their actual bytes rather than reserving a worst-case 8 MiB slot per request. When active leases and pending transfers cannot fit the budget, the request fails clearly rather than growing memory or waiting forever. Abort, failed reads and oversized streams release their counters and cancel the body.

The frame-preparation path carries idempotent leases until the presenter finishes submitting or rejecting the patch. A failed multi-image preparation releases every acquired lease; repeated URL/content references share the same cached entry. Origin assets are never evicted or rewritten.

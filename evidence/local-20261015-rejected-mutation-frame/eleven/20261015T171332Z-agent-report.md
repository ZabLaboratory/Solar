## Change under qualification

When a replacement Vision `load` fails for an active persistent session,
`mountVisionSceneNow` still sets the old message handler to a no-op, sends
`clear-scene` to the Rust engine, and rethrows the original Vision error. It no
longer sets the active layer opacity to zero. The front canvas is retained by the
host element and its last accepted frame remains visible. First loads and
prewarmed sessions continue to start hidden because their layer starts at opacity
zero. The focused unit tests exercise both paths and then load a valid replacement
in the same engine.

The native callback path was also traced. A malformed active subscription causes
the receive callback to fail, the native runtime to close that peer and reconnect,
and the corrected authoritative state to be accepted as a new
`lsdp.state.read/1` snapshot. That snapshot changes the Solar host status from
`connecting` to `live` but does not dispatch `solar:lsdp-applied`; this proof does
not invent such a receipt. A later collection mutation and a separate scalar
mutation each have their own real `applied` event and pixel comparison.
